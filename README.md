# Rick And Morty characters app

Два варианта реализации

## Реализация
### 1. Bloc + GetIt

- flutter_bloc — управление состоянием
- get_it — внедрение зависимостей

### 2. YX Scope + YX State

- yx_scope — управление зависимостями и жизненным циклом объектов
- yx_state — управление состоянием приложения
